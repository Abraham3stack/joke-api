# 🇳🇬 Nigerian Joke API 😂

A simple API that returns random Nigerian jokes.

---

## 🚀 Base URL
https://joke-api-jdve.onrender.com

---

## 📌 Endpoint

### Get a random joke

GET /joke

---

## 🧾 Example Response

{
  "joke": "NEPA took light during my online exam… I submitted faith."
}

---

## 🛠 Built With

- Node.js
- Express
- CORS

---

## 💡 About

This is a simple project built for learning how APIs work.  
It returns random Nigerian jokes when you hit the endpoint.

---

## ▶️ Run Locally

npm install  
node server.js  

Then open:  
http://localhost:3000/joke
